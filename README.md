# Pennywise - Shared Expense Tracker

Pennywise is a mobile application built with React Native (Expo) and a Node.js/Express REST backend to help friends, roommates, and travel groups manage and simplify shared expenses.

## Project Architecture
- `backend/` - Node.js, Express.js, MongoDB (Mongoose), JWT Auth REST API
- `frontend/` - React Native (Expo), Context API, React Navigation 6, Axios

See the detailed setup and folder guide in the documentation.
